## Get Broker

Returns details for a single broker in the Canada region.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | The broker ID |

### Response

```json
{
  "id": "b2",
  "name": "Northern Securities",
  "region": "CA",
  "status": "active"
}
```
