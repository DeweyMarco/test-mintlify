## Overview

The Quotes API is a lightweight REST service for fetching inspirational, philosophical, and technology-focused quotes on demand. It's designed to be dropped into any app, website, or script that needs a steady supply of well-attributed quotes — think daily-quote widgets, chatbots, onboarding screens, loading states, or AI prompts.

### What it does

- **Serves a curated quote library** across five categories: **motivation**, **wisdom**, **philosophy**, **technology**, and **marco original**.
- **Returns a random quote** on demand via `GET /quotes/random`, optionally scoped to a category.
- **Lists and filters quotes** via `GET /quotes`, so you can paginate or pull every quote in a category.
- **Looks up specific quotes by ID** via `GET /quotes/{id}` for permalinks or saved favorites.
- **Exposes the category list** via `GET /categories` so clients can build dynamic filters without hard-coding values.

Every response is JSON with a consistent shape — `id`, `text`, `author`, and `category` — and errors follow a predictable structure. There's no authentication, no rate-limiting headers to manage, and no SDK to install: a single `fetch` or `curl` call is all you need.

## Available endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/quotes` | List all quotes, with optional filters |
| `GET` | `/quotes/random` | Get a random quote |
| `GET` | `/quotes/{id}` | Get a specific quote by ID |
| `GET` | `/categories` | List available categories |

## Response format

All successful responses return JSON. Errors follow a consistent shape:

```json
{
  "error": "invalid_category",
  "message": "Category 'foo' does not exist. Valid categories: marco original, motivation, philosophy, technology, wisdom"
}
```

## Categories

You can filter quotes by category. The active categories are:

| Category | Description |
| --- | --- |
| `marco original` | Original quotes by Marco |
| `motivation` | Motivational and inspirational quotes |
| `philosophy` | Philosophical quotes |
| `technology` | Technology-related quotes |
| `wisdom` | Quotes about wisdom and life lessons |

## No authentication required

This API is open — no API keys or tokens needed.
