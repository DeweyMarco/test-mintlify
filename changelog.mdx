<Update label="2026-04-14" description="Week of April 14, 2026" tags={["New", "Update"]}>
  ## New: LLM-ready documentation

  The Quotes API docs now include [`llms.txt`](/llms.txt) and [`llms-full.txt`](/llms-full.txt). These plain-text summaries help AI tools and large language models understand the API. Use `llms.txt` for a quick overview or `llms-full.txt` when you need full request and response details. See the [introduction](/introduction) page for usage examples.

  ## Update: Simplified API surface

  The versioned Trading API (v1, v2, v3), Broker API, and regional navigation have been retired. All four endpoints now live under a single API with no version or region prefixes: [Get random quote](/api-reference/get-random-quote), [List quotes](/api-reference/list-quotes), [Get quote by ID](/api-reference/get-quote-by-id), and [List categories](/api-reference/list-categories). If you were using Trading API or Broker API endpoints, switch to the equivalent Quotes API paths. Request and response formats remain the same.

  ## Update: Willow theme

  The docs site now uses the Willow theme with improved dark mode contrast and a cleaner visual style.
</Update>

<Update label="2026-04-13" description="Week of April 13, 2026" tags={["New", "Update"]}>
  ## New: Trading API, Broker API, and regional navigation

  Three versioned Trading API products launched alongside a new Broker API for discovering broker details. The docs organized content by region with a sidebar dropdown to switch between API products. These APIs later merged into the single Quotes API surface in the [April 14 update](#2026-04-14).

  ## New: Interactive API playground

  Every API reference page now includes a built-in playground. Adjust parameters and see live responses without leaving the docs.

  ## Update: Revised API description

  The Quotes API description now reads "A lightweight REST API for fetching quotes by category," giving you a clearer picture of what the API does at a glance.

  ## Update: Visual refresh

  The docs have a new look with the Geist font, updated colors, breadcrumb navigation, and refined code block styling for better readability.
</Update>

<Update label="2026-04-02" description="Week of April 2, 2026" tags={["New", "Breaking"]}>
  ## New "marco original" category

  A new `marco original` category is now available, featuring an original quote by Marco Dewey. Filter by it using the [Get random quote](/api-reference/get-random-quote) or [List quotes](/api-reference/list-quotes) endpoints.

  ## Humor category removed

  The `humor` category is now fully removed. It no longer appears in the schema or returns any results.

  The active categories are now: `marco original`, `motivation`, `philosophy`, `technology`, and `wisdom`. See the [List categories](/api-reference/list-categories) endpoint for the current list.
</Update>
