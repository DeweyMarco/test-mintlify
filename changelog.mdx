<Update label="2026-04-13" description="Week of April 13, 2026" tags={["New"]}>
  ## Trading API

  Three versions of the Trading API are now available:

  - **[Trading API v1](/us/trading-v1/introduction)** — Access the [Get random quote](/us/api-reference/get-random-quote) and [List quotes](/us/api-reference/list-quotes) endpoints.
  - **[Trading API v2](/us/trading-v2/introduction)** — Access the [Get quote by ID](/us/api-reference/get-quote-by-id) endpoint.
  - **[Trading API v3](/us/trading-v3/introduction)** — Access the [List categories](/us/api-reference/list-categories) endpoint.

  ## Broker API

  A new [Broker API](/us/broker/introduction) is now available with two endpoints:

  - [List brokers](/us/broker-api/list-brokers) — Returns all brokers available in your region.
  - [Get broker](/us/broker-api/get-broker) — Retrieve details for a specific broker by ID.

  ## Interactive API playground

  You can now test endpoints directly from the docs. Each [API reference](/us/api-reference/get-random-quote) page includes a playground where you can adjust parameters and see responses in real time — no external tools needed.

  ## Regional docs navigation

  The documentation is now organized by region with versioned navigation. You can switch between API products using the dropdown in the sidebar.
</Update>

<Update label="2026-04-02" description="Week of April 2, 2026" tags={["New", "Breaking"]}>
  ## New "marco original" category

  A new `marco original` category is now available, featuring an original quote by Marco Dewey. Filter by it using the [Get random quote](/api-reference/get-random-quote) or [List quotes](/api-reference/list-quotes) endpoints.

  ## Humor category removed

  The `humor` category has been fully removed. It no longer appears in the schema or returns any results.

  The active categories are now: `marco original`, `motivation`, `philosophy`, `technology`, and `wisdom`. See the [List categories](/api-reference/list-categories) endpoint for the current list.
</Update>
