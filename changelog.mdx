<Update label="2026-04-13" description="Week of April 13, 2026" tags={["New", "Update"]}>
  ## Trading API

  You can now access quotes through three versioned Trading API products, each scoped to specific endpoints:

  - **[Trading API v1](/us/trading-v1/introduction)** — [Get random quote](/us/api-reference/get-random-quote) and [List quotes](/us/api-reference/list-quotes)
  - **[Trading API v2](/us/trading-v2/introduction)** — [Get quote by ID](/us/api-reference/get-quote-by-id)
  - **[Trading API v3](/us/trading-v3/introduction)** — [List categories](/us/api-reference/list-categories)

  Choose the version that includes the endpoints you need.

  ## Broker API

  A new [Broker API](/us/broker/introduction) lets you discover and retrieve broker details in the US region. Two endpoints are available:

  - [List brokers](/us/broker-api/list-brokers) — returns all brokers in your region
  - [Get broker](/us/broker-api/get-broker) — retrieve details for a specific broker by ID

  Each endpoint includes request examples and documents error responses, so you can integrate without guesswork.

  ## Interactive API playground

  Every [API reference](/us/api-reference/get-random-quote) page now includes a built-in playground. Adjust parameters and see live responses without leaving the docs.

  ## Updated API description

  The Quotes API description across [API reference](/us/api-reference/get-random-quote) pages now reads "A lightweight REST API for fetching quotes by category," giving you a clearer picture of what the API does at a glance.

  ## Production base URL coming soon

  The Quotes API is moving beyond local development. A hosted production base URL will be available shortly, so you can integrate without running the server locally. The server description in the API reference now reflects this upcoming change. Check the [introduction](/introduction) page for updates.

  ## Regional navigation

  The docs are now organized by region. Use the sidebar dropdown to switch between API products — Quotes API, Trading API versions, and Broker API.

  ## Visual refresh

  The docs have a new look with a cleaner theme, the Geist font, breadcrumb navigation, and refined code block styling.
</Update>

<Update label="2026-04-02" description="Week of April 2, 2026" tags={["New", "Breaking"]}>
  ## New "marco original" category

  A new `marco original` category is now available, featuring an original quote by Marco Dewey. Filter by it using the [Get random quote](/api-reference/get-random-quote) or [List quotes](/api-reference/list-quotes) endpoints.

  ## Humor category removed

  The `humor` category has been fully removed. It no longer appears in the schema or returns any results.

  The active categories are now: `marco original`, `motivation`, `philosophy`, `technology`, and `wisdom`. See the [List categories](/api-reference/list-categories) endpoint for the current list.
</Update>
