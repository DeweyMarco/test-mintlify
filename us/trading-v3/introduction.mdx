## Overview

Trading API v3 provides access to the categories endpoint, allowing you to discover all available quote categories. Use it to build dynamic filters or validate category values before making requests to other API versions.

## Base URL

```
https://api.us.example.com/v3
```

## Available endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/categories` | [List categories](/us/api-reference/list-categories) |

## Quick example

List all available categories:

```bash
curl https://api.us.example.com/v3/categories
```

```json
{
  "categories": [
    "marco original",
    "motivation",
    "philosophy",
    "technology",
    "wisdom"
  ]
}
```

## When to use Trading API v3

Use this version when you need to:

- Build a category picker or dropdown in your UI
- Validate category values before passing them to other endpoints
- Check which categories are currently active
