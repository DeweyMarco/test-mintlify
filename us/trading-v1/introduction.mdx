## Overview

Trading API v1 provides access to a subset of the Quotes API focused on browsing and discovering quotes. Use it to fetch random quotes or list quotes with optional filters.

## Base URL

```
https://api.us.example.com/v1
```

## Available endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/quotes` | [List quotes](/us/api-reference/list-quotes) with optional category and limit filters |
| `GET` | `/quotes/random` | [Get a random quote](/us/api-reference/get-random-quote), optionally restricted by category |

## Quick example

Fetch a random quote:

```bash
curl https://api.us.example.com/v1/quotes/random
```

```json
{
  "id": "7",
  "text": "Yesterday I was clever, so I wanted to change the world. Today I am wise, so I am changing myself.",
  "author": "Rumi",
  "category": "wisdom"
}
```

List quotes filtered by category:

```bash
curl "https://api.us.example.com/v1/quotes?category=motivation&limit=2"
```

## When to use Trading API v1

Use this version when you need to:

- Display a random quote to users (e.g., a quote-of-the-day widget)
- Browse and filter quotes by category
- Retrieve multiple quotes at once with pagination
