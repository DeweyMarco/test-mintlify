## Overview

Trading API v2 provides direct access to individual quotes by their unique identifier. Use it when you already know which quote you want to retrieve.

## Base URL

```
https://api.us.example.com/v2
```

## Available endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/quotes/{id}` | [Get a quote by ID](/us/api-reference/get-quote-by-id) |

## Quick example

Retrieve a specific quote:

```bash
curl https://api.us.example.com/v2/quotes/1
```

```json
{
  "id": "1",
  "text": "The only way to do great work is to love what you do.",
  "author": "Steve Jobs",
  "category": "motivation"
}
```

If the quote does not exist, the API returns a `404` error:

```json
{
  "error": "not_found",
  "message": "Quote with ID '999' does not exist."
}
```

## When to use Trading API v2

Use this version when you need to:

- Fetch a specific quote you've previously stored or bookmarked
- Build detail views that display a single quote by its ID
- Link directly to a known quote
