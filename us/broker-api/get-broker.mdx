## Get broker

Returns details for a single broker in the US region.

### Path parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | The broker ID |

### Request

```bash
curl https://api.us.example.com/broker/brokers/b1
```

### Response

```json
{
  "id": "b1",
  "name": "Acme Brokerage",
  "region": "US",
  "status": "active"
}
```

### Errors

If the broker ID does not exist, the API returns a `404` error:

```json
{
  "error": "not_found",
  "message": "Broker with ID 'invalid' does not exist."
}
```
