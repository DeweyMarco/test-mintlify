## Get Broker

Returns details for a single broker in the US region.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | The broker ID |

### Response

```json
{
  "id": "b1",
  "name": "Acme Brokerage",
  "region": "US",
  "status": "active"
}
```
