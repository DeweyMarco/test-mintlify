## List brokers

Returns all brokers available in your region.

### Request

```bash
curl https://api.us.example.com/broker/brokers
```

### Response

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique broker identifier |
| `name` | string | Broker display name |
| `region` | string | Region the broker operates in |

```json
{
  "brokers": [
    { "id": "b1", "name": "Acme Brokerage", "region": "US" },
    { "id": "b2", "name": "Northern Securities", "region": "CA" }
  ]
}
```
